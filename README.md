# Jobnect Arena

Agentic Job Portal System

---

**Jobnect Arena** is an open-source, agentic job portal system designed to streamline job searches and hiring. With a flexible, modular architecture and intelligent automation, this system empowers both job seekers and employers.

---

## 🚀 Features

- **Agentic Automation:** Smart agents for job matching, recommendations, and application tracking
- **Dedicated Portals:** Tailored experiences for both job seekers and employers
- **Real-time Notifications:** Stay updated with instant alerts
- **Supabase Integration:** Scalable backend with authentication and storage
- **Modern UI/UX:** Responsive, clean, and accessible frontend
- **TypeScript Codebase:** Safer and more maintainable
- **Easy Deployment:** Ready for cloud hosting

---

## 🛠️ Tech Stack

| Layer      | Technology                     |
|------------|-------------------------------|
| Frontend   | React (with TypeScript), Tailwind CSS |
| Backend    | Supabase (Postgres, Auth)     |
| Tooling    | Bun, Vite, ESLint             |
| Languages  | TypeScript (98.7%), Others    |

## 🚩 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) and [Bun](https://bun.sh/)
- [Git](https://git-scm.com/)
- [Supabase](https://supabase.com/) account

---

### Installation

```bash
git clone https://github.com/SIDDU2402/jobnect-arena.git
cd jobnect-arena
```
### Install dependencies with Bun
```bash
 npm install
```
### Run Locally
```bash
npm run dev
```
